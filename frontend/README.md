# Task Management Frontend

React + Vite frontend for the Task Management System.

## Setup

```bash
npm install
npm run dev
```

The app runs at:

```text
http://localhost:5173
```

The backend API should be running at:

```text
https://localhost:7218/api
```

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

## Main Areas

- Public landing pages
- Auth pages for login, register, forgot password, and reset password
- User dashboard and task management
- User smart task lists: Inbox, Today, Starred
- User profile management
- Admin dashboard
- Admin users and task management
